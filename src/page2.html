Описание проблемы

При попытке добавить товар в корзину и перейти к оформлению заказа кнопка "Купить" остается неактивной. Проблема воспроизводится стабильно на всех тест-кейсах с товарами свыше 1000 руб.

Окружение (Environment)

  • Браузер: Google Chrome 122.0.6261.94
  • OS: Windows 11 (64-bit)
  • URL: https://example.com/cart
  • Разрешение экрана: 1920x1080
  • Сеть: Wi-Fi (стабильное соединение)

Шаги воспроизведения

  1. Перейти на главную страницу: https://example.com/
  2. Выбрать товар "Ноутбук XYZ" и нажать "Добавить в корзину".
  3. Перейти в корзину по ссылке "Корзина" (иконка в хедере).
  4. Нажать кнопку "Оформить заказ" / "Купить".

Ожидаемый результат (Expected Result)

Открывается форма оформления заказа с предзаполненными данными из корзины. Товар добавляется в заказ.

Фактический результат (Actual Result)

Кнопка "Купить" не реагирует на клик. В консоли браузера (F12 > Console) ошибка: TypeError: Cannot read property 'submit' of null.
